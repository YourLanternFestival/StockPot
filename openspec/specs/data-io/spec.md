# 数据导入导出

## 概述
处理 xlsx 文件的导入和导出，用于批量数据操作。

## 导入

导入入口分散在各页面，各管自己的数据类型。每次只面对 3-6 个字段，智能匹配列名，支持追加或覆盖模式。

### 需求：产品导入
产品管理页 → "导入产品"按钮 → 选文件 → 智能映射 6 字段 → 追加或覆盖 → 预览 → 执行。

#### 场景：导入产品（追加模式）
- 假设 用户选择包含产品数据的 xlsx 文件
- 当 系统自动匹配列名后用户确认
- 那么 新产品被导入，已有同名产品被跳过

#### 场景：导入产品（覆盖模式）
- 假设 用户选择覆盖模式
- 当 确认二次弹窗后
- 那么 先清空所有产品，再导入新数据

### 需求：入库记录导入
入库登记页 → "导入入库"按钮 → 选文件 → 智能映射 6 字段 → 追加或覆盖 → 预览 → 执行。

#### 场景：导入入库
- 假设 用户选择包含入库记录的 xlsx
- 当 系统自动匹配列名
- 那么 入库记录被导入（追加或覆盖）

### 需求：出库记录导入
出库登记页 → "导入出库"按钮 → 选文件 → 智能映射 4 字段 → 追加或覆盖 → 预览 → 执行。

### 需求：智能列匹配
系统读取 Excel 第一行作为表头，按优先级匹配：
1. 精确匹配：表头 == 字段 label
2. 别名匹配：表头 ∈ 字段 aliases（如 "品名" → 材料名称）
3. 包含匹配：表头包含字段 label（≥2 字）

匹配结果展示确认表，用户可手动调整映射。

#### 场景：自动匹配成功
- 假设 Excel 表头为 "材料名称"、"规格"、"单位"
- 当 系统读取表头
- 那么 name → "材料名称"（精确），spec → "规格"（精确），unit → "单位"（精确）
- 且 显示绿色 ✓ 已匹配

#### 场景：别名匹配
- 假设 Excel 表头为 "品名"
- 当 系统读取表头
- 那么 "品名" 通过别名匹配到 name 字段

#### 场景：必填字段未匹配
- 假设 "材料名称" 字段未匹配到任何列
- 那么 显示红色 ✗ 未匹配
- 且 执行导入时提示错误

### 需求：追加/覆盖模式
每个导入弹窗提供双模式选择：
- **追加**（默认）：产品按名称去重，记录追加
- **覆盖**：先清空该类型全部数据，再导入，有二次确认

### 需求：预览前5行
映射确认后可预览解析结果，验证列对应正确后再执行。

## 导出

### 需求：库存快照导出
系统应将当前库存水平导出为 xlsx。

### 需求：月度台账导出
系统应将月度台账数据（含日明细）导出为 xlsx。

### 需求：勾选式多选导出
台账页 → "导出数据..."按钮 → 弹窗勾选数据类别 → 同一工作簿分 sheet 导出。

#### 场景：多选导出
- 假设 用户点击台账页"导出数据..."
- 当 弹窗显示四个复选框（产品/入库/出库/台账）
- 那么 默认勾选前三项
- 且 用户勾选后点击导出
- 那么 生成一个 Excel 文件，每个选中类别一个 sheet

### 需求：采购单导出
系统应通过 ExcelJS 将采购单导出为带嵌入产品图片的 Excel。

#### 场景：文件被占用时自动重试
- 假设 用户导出采购单到某文件
- 当 该文件已被 Excel 打开（EBUSY/EPERM）
- 那么 系统自动尝试以 `(2)`、`(3)` 等后缀保存到同目录，最多重试 10 次
- 且 成功后提示用户"文件被占用，已另存为 xxx(2).xlsx"

### 需求：历史采购单批量导出
系统应支持批量导出多天的历史采购单到一个 Excel 文件。

### 需求：clearAllData 全表清空
`db.js` 中的 `clearAllData()` 清空全部 9 张业务表。
使用事务：BEGIN → DELETE 所有表 → COMMIT → save。
失败 → ROLLBACK。

#### 场景：清空全部 9 张表
- 假设 调用 clearAllData()
- 那么 全部 9 张业务表的数据被删除

#### 场景：事务原子性
- 假设 清空过程中某表删除失败
- 那么 整个事务回滚，所有数据保持不变
